# Gouldmine

This project is about training RL algorithms to play musical instruments. By exploring how different RL algorithms or reward functions change the agents output through the training process, we can hear how AI learns.

2. You may, of course, **offer suggestions**. I'm open to constructive criticism on all aspects of the project: code quality, algorithm optimization, interesting reward function / RL algorithm options, how my ideas could be rearranged into a proof of the Riemann hypothesis, it's all fair game.
